# SawMe
SawMe is a simple and lightweight live time and date website that automatically displays the current time, day, and date. The website updates every second in real time and works directly in the browser without requiring any backend or external services.

✨ Features:
🕐 Live clock updated every second
📅 Automatic date display
📆 Automatic day display
📱 Responsive design
⚡ No backend or database required
🌐 Works directly in modern browsers

🛠️ Built With:
HTML

🚀 How to Use:
Open index.html in your browser.
The current time, day, and date will automatically be displayed.
The clock updates every second.

🌐 GitHub Pages:
SawMe can be hosted using GitHub Pages.
Go to:

Settings → Pages → Deploy from branch → main → / (root)

Then open your generated GitHub Pages URL.
